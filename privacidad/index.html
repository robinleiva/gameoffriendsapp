2. Datos de perfil y edad

GAME OF FRIENDS puede tratar el Nick, fecha de nacimiento y/o edad derivada, país, zona, género si se solicita, preferencias de juego y dificultad. La fecha de nacimiento se utiliza para aplicar las reglas de edad y seguridad. El género no se utiliza para modificar la matriz de edad ni para habilitar funciones sociales restringidas.

3. Identificadores técnicos

Podemos utilizar identificadores internos de cuenta, dispositivo o sesión necesarios para reconocer el perfil, evitar duplicidades, sincronizar estado, mantener seguridad y operar el Servicio. No se deben recolectar identificadores técnicos que no sean necesarios para estas finalidades.

4. Datos de juego y aprendizaje

Podemos tratar preguntas respondidas, aciertos y errores, nivel seleccionado, progreso adaptativo, XP, ciclos, partidas, resultados, preferencias, historial de compañeros y otros datos necesarios para adaptar la experiencia pedagógica y operar el juego.

5. Datos sociales y moderación

Podemos tratar favoritos, bloqueos, relaciones de juego, invitaciones, reportes, motivo del reporte, estado de moderación y metadatos necesarios para seguridad. Para perfiles de 13 a 17 años sólo se habilita Chat Resguardado y no se permite escritura libre. Para adultos, el contenido de comunicaciones de formato libre puede procesarse en la medida necesaria para entregar la función, investigar reportes, prevenir abuso o cumplir obligaciones legales.

6. Datos de compras y suscripción

Para Premium podemos tratar el producto adquirido, estado de la suscripción, fechas de inicio, renovación y expiración, identificadores o tokens de compra tratados de forma segura, y el vínculo entre el derecho Premium y la cuenta GAME OF FRIENDS. Estos datos se utilizan para verificar, restaurar, renovar, suspender o retirar Premium y prevenir fraude. Google Play procesa el medio de pago; GAME OF FRIENDS no necesita almacenar los datos completos de tarjeta.

7. Publicidad recompensada

Si el usuario utiliza anuncios recompensados, se podrán tratar eventos necesarios para solicitar, mostrar y confirmar la recompensa. Para perfiles de 13 a 17 años, GAME OF FRIENDS utilizará publicidad no personalizada y configurará los servicios publicitarios conforme a la edad y las políticas aplicables. Para adultos, la configuración publicitaria se ajustará a la legislación, consentimiento y políticas de plataforma que correspondan.

8. Finalidades

Usamos los datos para crear y reconocer perfiles; aplicar seguridad por edad; realizar matchmaking; gestionar partidas y progreso adaptativo; otorgar XP y premios; operar funciones sociales; moderar y prevenir abusos; atender soporte; gestionar suscripciones; acreditar publicidad recompensada; diagnosticar fallas; mantener seguridad; cumplir obligaciones legales y mejorar el Servicio.

9. Proveedores y transferencias

GAME OF FRIENDS puede utilizar proveedores de distribución y facturación como Google Play y Google Play Billing, servicios publicitarios como Google Mobile Ads/AdMob cuando estén activos, y proveedores de alojamiento, base de datos, seguridad e infraestructura necesarios para operar el backend. Cuando el tratamiento implique transferencias internacionales, se aplicarán las medidas y salvaguardas exigibles según la legislación aplicable.

10. Menores y adolescentes

GAME OF FRIENDS no permite cuentas de menores de 13 años en producción. Los perfiles de 13 a 17 años pueden utilizar las funciones de juego compatibles con su edad y Chat Resguardado, pero no pueden acceder a Chat Libre, Chat Premio ni Chat Premium. Premium pagado está reservado a perfiles de 18 años o más.

11. Conservación

Los datos de perfil y progreso se conservan mientras la cuenta permanezca activa y se eliminan o desvinculan cuando corresponde conforme a la política de eliminación. Los registros de seguridad y moderación se conservan durante el tiempo razonablemente necesario para investigar incidentes, prevenir abuso y ejercer o defender derechos. Los registros de suscripción y compra se conservan durante el período necesario para facturación, soporte, fraude, obligaciones contables o tributarias y resolución de disputas. Los registros técnicos se conservan durante el tiempo necesario para seguridad, diagnóstico y estabilidad. Los registros de solicitudes de privacidad o eliminación pueden conservarse durante el tiempo necesario para acreditar su tramitación y cumplir obligaciones legales.

12. Eliminación de cuenta

El usuario puede solicitar la eliminación desde la aplicación o desde https://gameoffriendsapp.com/eliminar-cuenta. Algunos datos pueden conservarse o desvincularse cuando exista una obligación legal, fiscal, antifraude, de seguridad o de resolución de disputas, exclusivamente para esa finalidad. Eliminar la cuenta no cancela automáticamente una suscripción de Google Play.

13. Derechos

Los usuarios pueden ejercer los derechos reconocidos por la legislación aplicable respecto de sus datos personales mediante el correo gameoffriends.app@gmail.com o los demás canales de contacto indicados en esta Política. GAME OF FRIENDS atenderá las solicitudes conforme a los requisitos y plazos legales aplicables.

14. Seguridad

GAME OF FRIENDS aplicará medidas técnicas y organizativas razonables para proteger la información contra acceso, alteración, pérdida o divulgación no autorizados. Ningún sistema conectado puede garantizar un riesgo cero.

15. Cambios

Esta Política puede actualizarse cuando cambien el Servicio, la arquitectura, los proveedores o las obligaciones legales. Los cambios materiales se comunicarán cuando corresponda.
