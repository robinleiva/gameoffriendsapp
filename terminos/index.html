2. Servicio y definición de duelo

GAME OF FRIENDS es un juego de trivia multijugador para Android que permite competir, aprender, acumular progreso y utilizar funciones sociales compatibles. A efectos de estos Términos, un “duelo” es una partida de GAME OF FRIENDS compuesta actualmente por cinco preguntas.

3. Edad mínima y fecha de nacimiento

El Servicio está disponible para perfiles de 13 años o más. Los menores de 13 años no pueden registrarse ni utilizar la versión de producción. La fecha de nacimiento declarada se utiliza para calcular la edad y aplicar protecciones. Mientras exista la cuenta, esa fecha no podrá modificarse para eludir restricciones.

4. Matriz de comunicación por edad

Los usuarios de 13 a 17 años pueden participar en las funciones de juego compatibles con su edad, incluidos duelos con otros jugadores cuando el matchmaking lo permita, pero sólo disponen de Chat Resguardado. Para perfiles de 13 a 17 años quedan bloqueados Chat Libre, Chat Premio y Chat Premium.

Los usuarios de 18 años o más pueden acceder, cuando cumplan las demás condiciones de progreso, seguridad, bloqueo y moderación, a Chat Resguardado, Chat Libre, Chat Premio y Chat Premium.

5. Perfil, juego, progreso y elementos virtuales

El usuario debe proporcionar datos correctos. GAME OF FRIENDS puede utilizar identificadores internos, Nick, edad derivada, preferencias, progreso, XP, niveles, resultados e historial necesarios para operar el Servicio.

XP, premios, minutos obtenidos gratuitamente mediante progreso, relación o publicidad, favoritos y otros elementos virtuales no constituyen dinero ni un derecho de cobro fuera del Servicio. Esta regla no elimina ni reduce los derechos del consumidor asociados a una suscripción Premium pagada ni los derechos de reembolso o compensación que correspondan legalmente.

6. Funciones sociales y contenido generado por usuarios

Chat Resguardado utiliza frases, respuestas y elementos predeterminados y no permite escritura libre.

Chat Libre es una sesión temporal de comunicación de formato libre reservada a perfiles de 18 años o más que cumplan las reglas de progreso, seguridad y moderación.

Chat Premio es una sesión temporal de Chat Libre financiada con minutos de premio de relación obtenidos dentro del juego. También está reservada a perfiles de 18 años o más.

Chat Premium es una sesión temporal vinculada a la suscripción Premium y sólo puede operar entre adultos compatibles de 18 años o más.

Antes de usar funciones de contenido generado por usuarios, el usuario deberá aceptar las reglas aplicables.

7. Conductas prohibidas

No se permite acosar, amenazar, sexualizar o explotar a menores, solicitar datos sensibles, suplantar identidades, estafar, realizar spam, evadir controles de edad, vulnerar el sistema o utilizar el Servicio para actividades ilícitas.

8. Seguridad, bloqueo, denuncia y moderación

GAME OF FRIENDS puede aplicar medidas de bloqueo, denuncia y moderación. Una denuncia no produce una sanción automática. Las medidas pueden incluir advertencias, restricciones o suspensión según gravedad, contexto, reincidencia y antecedentes disponibles.

9. Premium

Premium es una función de pago separada reservada a perfiles de 18 años o más. Premium nunca elimina restricciones de edad, bloqueo, seguridad o moderación. Las condiciones económicas y beneficios específicos se describen en los Términos Premium.

10. Publicidad recompensada

GAME OF FRIENDS puede ofrecer publicidad recompensada voluntaria. Las recompensas sólo se conceden cuando el sistema confirma que se cumplieron las condiciones. Para perfiles de 13 a 17 años, GAME OF FRIENDS utilizará publicidad no personalizada y aplicará la configuración de edad y seguridad que corresponda.

11. Disponibilidad

El Servicio puede experimentar mantenimiento, fallas de red, incompatibilidades o incidentes técnicos. Se procurará una operación razonable. Esta cláusula no limita derechos irrenunciables del consumidor.

12. Eliminación de cuenta

El usuario puede solicitar la eliminación desde la aplicación y desde la página pública https://gameoffriendsapp.com/eliminar-cuenta. Eliminar una cuenta no cancela automáticamente una suscripción de Google Play. Si existe Premium activo, la aplicación y la página pública deberán advertirlo y ofrecer instrucciones para administrar o cancelar la suscripción antes de completar la eliminación.
